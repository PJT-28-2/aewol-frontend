# 애월 (AeWol) — Frontend

> 반려동물 디지털 지갑 서비스

## 기술 스택

| 구분 | 기술 |
|------|------|
| Framework | Vue.js 3 |
| State Management | Pinia |
| Build Tool | Vite |
| Language | TypeScript |
| Package Manager | npm |

## 로컬 개발 환경

### 사전 요구사항

- Node.js 20+
- npm

### 설치 및 실행

```bash
npm install
npm run dev
```

### 빌드

```bash
npm run build
```

## 브랜치 전략

```
main ← develop ← feature/{이슈번호}-{기능명}
```

| 브랜치 | 용도 |
|--------|------|
| `main` | 프로덕션 배포 |
| `develop` | 개발 통합 |
| `feature/*` | 기능 개발 |
